秘書くん プライバシーポリシー

CRASIO株式会社（以下「当社」）は、業務支援ツール「秘書くん」（以下「本サービス」）におけるお客様の情報の取り扱いについて、以下のとおり定めます。

1. 取得する情報

本サービスは、利用者がGoogleアカウントで接続を許可した場合に、次の情報を取り扱います。

  • Googleカレンダーの予定情報（予定名、日時、参加者など）
  • Google Meetの会議リンク作成に必要な情報
  • LINEで送られたメッセージ・画像・ファイル（業務上の連絡に限る）

2. 利用目的

取得した情報は、次の目的にのみ利用します。

  • 予定の登録・確認、会議リンクの作成
  • 送られた連絡事項の整理、回答、リマインド通知

3. Googleユーザーデータの扱い

本サービスによる Google API から取得した情報の利用は、Google API サービスユーザーデータポリシー（限定利用の要件を含む）に従います。取得した情報を広告目的に使用すること、第三者に販売することはありません。

4. 第三者への提供

法令に基づく場合を除き、取得した情報を第三者に提供しません。本サービスの運用に必要な範囲で、外部の基盤（クラウド、AI等）を利用する場合があります。

5. 保管と安全管理

Googleの接続情報（アクセストークン等）は、当社のサーバーに保存し、外部から読み取れないように管理します。不要になった情報は速やかに削除します。

6. 接続の解除

利用者は、Googleアカウントの「サードパーティ製のアクセス」から、いつでも本サービスとの接続を解除できます。
